# Курс за курсом

Личный трекер обучения: **«Мои курсы»**, свои предметы, план, прогресс и сертификаты. На основном сайте сохранены 109 исходных позиций и план из 28 курсов при выборе обеих версий архитектуры. Новая личная копия другого владельца начинает с пустых предметов, каталога и плана — их можно заполнить через расширение Coursera, самостоятельно или из Excel.

Основной сайт: **[Курс за курсом](https://rumm1.github.io/aitu-course-tracker/)**.

## Курсы и оформление

- Поиск, свои предметы, статусы и закреплённые приоритеты. На основном сайте сохранены исходные предметы CAP, SEC, QA, ARCH и TE с английскими названиями и варианты UML / Go.
- Карточки и компактный список с одинаковыми действиями и фактическим прогрессом.
- На основном сайте исходный каталог находится во вкладке **«Основные»**, новые курсы из Coursera и Excel — во вкладке **«Дополнительные»**. Счётчики и поиск относятся к выбранному разделу. «Мой план», предметы и «Пройденные» учитывают оба раздела; принадлежность к дополнительным не сбрасывает отметки и не исключает курс из плана. В новых личных копиях без исходного каталога все свои курсы отображаются во вкладке «Мои курсы».
- [Пройденные курсы](https://rumm1.github.io/aitu-course-tracker/#completed) вынесены в отдельный раздел и сгруппированы по основному предмету. Один стабильный ID учитывается один раз, даже при связях с несколькими предметами и неделями.
- Чёрная, зелёная и красная палитра объединяет обе темы, сайт и расширение. PNG-логотип, компактные панели и строгие углы оформлены согласованно. Тема и вид каталога запоминаются, анимации учитывают уменьшение движения в системе.
- Прохождение курса, покрытие темы и решение университета о зачёте отмечаются отдельно. Ориентиры 90+ и 95 — плановые значения, а не полученные оценки.

Дедлайн — **10 ноября 2026 включительно**, Казахстан (UTC+5). Отсчёт заканчивается `2026-11-11T00:00:00+05:00`. После этого материалы и отметки остаются доступны.

## Свой сайт для каждого владельца

Каждый знакомый создаёт **свой репозиторий и свой адрес GitHub Pages**. Это отдельная копия приложения; личные Excel-курсы, проценты и отметки владельца исходного сайта в неё не попадают.

1. Войдите в свой GitHub и откройте **[создание личной копии из шаблона](https://github.com/Rumm1/aitu-course-tracker/generate)**.
2. Создайте репозиторий в своём аккаунте с веткой `main`. Для GitHub Pages на бесплатном личном тарифе используйте публичный репозиторий; личные файлы туда не добавляйте.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В **Actions** запустите **Publish GitHub Pages → Run workflow** и дождитесь успешных `build` и `deploy`.
5. Откройте фактический адрес из deployment / окружения `github-pages`. Формат project site: `https://USERNAME.github.io/REPOSITORY/`; для репозитория `USERNAME.github.io` — `https://USERNAME.github.io/`.
6. Добавьте свой Excel при необходимости. Скачайте расширение **со своего сайта**, в разделе «Расширение и свой сайт».

Сборка берёт адрес из `GITHUB_REPOSITORY` и создаёт ZIP расширения для конкретного владельца и пути Pages. В копии не нужно вручную менять ссылки в исходниках. ZIP основного сайта предназначен для основного адреса; другой личной копии нужен ZIP, собранный её workflow.

Hash-навигация позволяет обновлять адрес вида `/#completed` без серверного роутинга. После публикации достаточно открыть свой сайт; для ежедневного использования ничего запускать локально не требуется.

## Свои предметы и списки курсов

В разделе **«Мои предметы»** можно создать предмет с любым названием, переименовать его и выбрать курсы из своего каталога. Название не связано с обязательным кодом учебного плана — например, можно создать «Математика» и собрать подходящие курсы.

В окне «Выбрать курсы» есть поиск; отмеченные курсы остаются выбранными при смене запроса. Один курс может входить в несколько предметов. Это меняет только распределение: статусы, сертификаты, проценты и включение в план остаются прежними. Общий прогресс по-прежнему считает каждый курс один раз.

Предмет можно **скрыть** и затем **восстановить** из списка скрытых. Его название и связи сохраняются. Новая личная копия не навязывает исходные пять предметов основного сайта. Названия, распределение и видимость предметов входят в резервную копию JSON вместе с остальными личными настройками.

## Добавить курсы из Excel

В «Моих курсах» нажмите **«Добавить из Excel»** и выберите локальный `.xlsx` или `.xls`.

1. Выберите лист. Русские и английские заголовки распознаются автоматически, в том числе после строк с названием таблицы.
2. Проверьте колонки: название, ссылка, провайдер, предметы, тип, статус, процент, часы и включение в план. Читаются гиперссылки в ячейках и буквальные адреса `HYPERLINK`, без выполнения формул.
3. Просмотрите результат до применения. Новые курсы получают стабильные локальные ID, существующие сопоставляются с каталогом. Повторы в файле отмечаются и не добавляют копий.
4. Проверьте предметы. Названия из Excel сопоставляются с вашими предметами; новые имена показаны в предпросмотре и будут созданы при применении. Если предмет не указан, приложение может предложить его по названию курса. Неизвестное можно оставить не назначенным. Новый курс по умолчанию не увеличивает обязательный план — включение должно быть явным.
5. Примените выбранные строки. Каталог и отметки сохранятся после перезагрузки.

Ограничения: **20 МБ, 20 листов и 5000 строк данных**. Нужны HTTPS-ссылки без учётных данных и исполняемого кода. Программа и её дочерние курсы не объединяются по общей ссылке. Неверные и неоднозначные строки требуют проверки.

Формулы и макросы не выполняются. Расчётный балл 95, оценка, дата импорта или кэш формулы не подтверждают прохождение. Статус должен быть явным; неизвестная дата окончания остаётся неизвестной. Excel-даты сохраняются как календарные даты без выдуманной таймзоны. Файл разбирается на устройстве, без загрузки на сервер.

Используется локальная **SheetJS CE 0.20.3**; источник и лицензия описаны в [vendor/README.md](vendor/README.md).

## Проверить прогресс Coursera

На обзоре нажмите **«Проверить мой прогресс»**. Если включённое расширение уже прочитало результаты, трекер использует их. Иначе доступна массовая вставка.

1. Откройте [«Моё обучение» Coursera](https://www.coursera.org/my-learning), затем «Завершённые» или «В процессе». Загрузите нужные строки.
2. Скопируйте список целиком и вставьте в одно поле. Выберите соответствующий раздел. Для общей копии сохраните в тексте названия обоих разделов и выберите смешанный список.
3. Нажмите **«Учесть весь список»**. Точные названия и проверенные прежние названия применятся за одно действие. Ручной выбор нужен только для неоднозначных совпадений. Неизвестные названия не создают новые позиции — для своего каталога используйте Excel.

Повторная и неполная вставка не создаёт дубли, не стирает завершения, сертификаты и более высокий прогресс. Ручные исправления защищены, конфликты показываются отдельно.

Активная карточка показывает **«В процессе · 67%»**, если число есть в источнике. При явном числе выполненных и общих заданий процент помечается **«по заданиям»**. Без этих данных показано **«В процессе · процент пока неизвестен»**. Открытие ссылки, время на сайте и оценка не создают процент; одни лишь 100% не подтверждают завершение.

Завершённый курс исчезает из очереди продолжения и обновляется во всех связях. На обзоре видны **«Пройдено X из Y курсов моего плана · Z%»**, дата, результат и источник проверки. Для вставки источник — **«Вставленный список Coursera»**. Персональная ссылка сертификата появляется на завершённой карточке, когда получена; без неё курс остаётся пройденным.

## Расширение Chrome 1.3

ZIP доступен в разделе сайта **«Расширение и свой сайт»** и в [релизе v1.3.0 основного репозитория](https://github.com/Rumm1/aitu-course-tracker/releases/tag/v1.3.0). Владельцы личных копий скачивают ZIP со своего Pages — сборка привязана к их адресу.

1. Распакуйте ZIP в постоянную папку.
2. В `chrome://extensions` включите «Режим разработчика» → «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
3. В окне расширения подтвердите чтение своего списка и включите передачу прогресса.
4. Обновите Coursera и свой трекер. В «Моём обучении» откройте «Завершённые» и «В процессе», дождитесь карточек и загрузите нужные строки.

Для обновления замените файлы в **прежней папке**, нажмите ↻ у расширения в `chrome://extensions` и обновите Coursera и трекер. Метки трекера остаются в его отдельном хранилище.

Версия 1.3 читает все подходящие **отображаемые карточки Coursera**, а не только позиции начального каталога. Новые курсы с названием и допустимой официальной ссылкой автоматически добавляются в ваш локальный каталог вместе с доступным статусом и прогрессом. Сначала они находятся **без предмета** и не включаются в обязательный план. Затем распределите их в «Моих предметах»; один курс можно включить в несколько списков. Позиции из Excel также распознаются. Повторы объединяются по стабильному ID и ссылке, завершение не сбрасывается.

Если точную позицию по карточке установить нельзя, расширение не создаёт её наугад. В окне проверки показаны раздел, время чтения и причина, если данные не найдены.

Расширение читает только **отображённые** карточки. «Все» означает все загруженные на открытой странице карточки; это не скрытая загрузка всей истории аккаунта. Для старых завершений откройте «Завершённые» и загрузите нужные строки. Расширение не входит в аккаунт, не прокручивает список и не открывает скрытые разделы само. Результаты передаются внутри браузера; источник — **«Расширение браузера · видимая страница Coursera»**. На телефоне используйте вставку списка.

Это локальное чтение DOM, а не официальный API. Единственное API-разрешение расширения — `storage`. Пароли, cookies, токены и внутренние API не читаются; полный текст страницы не сохраняется. Перед входом в другой аккаунт Coursera выберите **«Отключить и очистить данные»**. Очистится кэш расширения; ранее сохранённые отметки трекера останутся.

Обычный вход в личный аккаунт не даёт GitHub Pages доступа к результатам через API. Официальные возможности описаны в [Coursera Developer Platform](https://dev.coursera.com/get-started); отдельный университетский адаптер требует предоставленного и разрешённого доступа.

## Сертификаты и отчёты

**PDF:** укажите имя владельца, как в документе, и загрузите файлы в «Сертификатах». Автоматическое сопоставление требует читаемого текста, признаков выдачи, совпадения владельца, названия, провайдера и вида документа. Скан без текста и неоднозначный документ остаются на проверку; OCR не включён. Сертификат программы не завершает её отдельные курсы. PDF.js и worker входят в сборку, URL извлекается из текста и аннотаций. Без URL можно открыть локальный PDF или добавить ссылку позднее.

**Папка:** в поддерживаемом настольном Chromium-браузере на HTTPS доступен `showDirectoryPicker`. Читаются PDF непосредственно из выбранной папки, без вложенных каталогов. Проверки выполняются при открытии, возвращении во вкладку и периодически, пока она видима. Восстановление разрешения вызывается кнопкой. Папку можно отключить; без этого API доступна загрузка нескольких PDF. Максимальный размер одного файла — 40 МБ.

**CSV / JSON отчёта:** нужны `courseId` или точное `title` и явный `status`; дополнительно — провайдер, дата, оценка и URL сертификата. CSV допускает запятую и точку с запятой и предлагает сопоставление колонок. JSON отчёта — массив записей или объект с массивом `rows`. Даты — `YYYY-MM-DD` или ISO 8601; время импорта не подставляется вместо окончания.

## Личные данные и резервные копии

Без входа каталог, отметки и настройки хранятся в **IndexedDB текущего браузера**, отдельно по origin и пути сайта. Поиск, фильтры и выбранная вкладка каталога сохраняются в localStorage. Один курс учитывается по канонической ссылке; одинаковые названия с разными ссылками автоматически не объединяются. Счётчик найденного относится к выбранному каталогу или плану. Курсы, программы и проекты можно фильтровать отдельно.

В разделе **«Аккаунт»** доступен вход по email и паролю через Supabase. После входа курсы, предметы, настройки, проценты и персональные ссылки сертификатов синхронизируются между устройствами. Новые аккаунты пустые. Владелец старой локальной копии нажимает **«Перенести мои локальные данные»** один раз; повторный перенос не добавляет дубли и не сбрасывает более полные результаты. Исходная локальная копия остаётся в браузере.

Облачная таблица защищена RLS по `auth.uid()`. Данные разных аккаунтов и репозиториев разделены. В публичном коде есть только URL проекта и **publishable key**; секретных административных ключей нет. Данные не загружаются в GitHub. Администратор вашего проекта Supabase имеет административный доступ к базе.

Синхронизация использует проверку версии и объединение независимых изменений. При недоступности облака правки сохраняются локально и отправляются после восстановления связи; интерфейс показывает фактическое состояние. Локальные PDF, документы импорта и разрешения на папку разделены по аккаунтам и не отправляются в облако. После входа автоматическое чтение расширения для этого аккаунта начинается с явного нажатия «Проверить мой прогресс».

В «Моих данных» используйте **«Экспорт JSON»** для переноса. Копия сохраняет отметки и локальные курсы; необязательный массив `courses` содержит их метаданные. Старые копии без массива совместимы. Перед применением импорт показывает совпадения и конфликты по ID.

JSON **не переносит PDF и разрешение на папку** — документы на другом устройстве загружаются заново. Копия содержит личные данные: храните её у себя и не добавляйте в публичный репозиторий. Очистка данных браузера, другой профиль, домен или путь сайта могут сделать прежнее хранилище недоступным. Без резервной копии удалённые локальные отметки восстановить нельзя.

Для первого открытия сайта нужна сеть. Полноценный офлайн-режим с service worker не включён. Настройка своего облака и отправки писем: [supabase/README.md](supabase/README.md).

## Разработка и проверки

Нужны Node.js 24 и npm. В PowerShell при ограничении `npm.ps1` используйте `npm.cmd`.

```sh
npm ci
npm test
npm run build
npm run test:browser
npm run dev
```

`npm run build` собирает расширение и сайт в `dist/`; ZIP создаётся в `public/course-progress-extension.zip` и включается в публикацию. Браузерные тесты используют отдельный headless Chrome; нужен установленный Google Chrome. Не открывайте `index.html` через `file://`: приложению нужны HTTP(S) и IndexedDB.

В GitHub Actions адрес расширения определяется из `GITHUB_REPOSITORY`. Для локальной сборки своей копии задайте адрес явно:

```powershell
$env:BASE_PATH = '/REPOSITORY/'
$env:GITHUB_REPOSITORY = 'USERNAME/REPOSITORY'
$env:TRACKER_URL = 'https://USERNAME.github.io/REPOSITORY/'
npm.cmd run build
Remove-Item Env:BASE_PATH
Remove-Item Env:GITHUB_REPOSITORY
Remove-Item Env:TRACKER_URL
```

`src/catalog.json` и `src/relations.json` содержат исходные данные; `src/excel-import.js` читает Excel; `src/core.js`, `src/storage.js`, `src/pdf.js` отвечают за расчёты и хранение; `src/progress-import.js` — за вставку; `src/extension-client.js` и `extension/` — за локальный перенос; `.github/workflows/pages.yml` публикует сайт.

Проверки охватывают каталог и уникальный прогресс, обе стороны границы дедлайна UTC+5, URL, импорт и сохранение прежних отметок, Excel XLS/XLSX, темы и фильтры, мобильную ширину, массовую вставку и расширение на DOM-образцах. Реальный авторизованный аккаунт Coursera при тестировании не использовался. Изменение разметки Coursera может потребовать обновления; вставка остаётся доступной. Тесты не заменяют проверку ваших реальных PDF и разрешений на папку.

При ошибке публикации откройте журнал Actions. При 404 проверьте источник Pages, успешный deployment и base path репозитория.

Персональная ссылка сертификата подставляется автоматически из карточки курса (включая ссылку, указанную в кнопке). Если Coursera открывает сертификат отдельной страницей, откройте её один раз: расширение прочитает адрес и точное название или ссылку курса. Неоднозначные страницы не привязываются; адрес сертификата не придумывается.

Интерфейс 1.3 использует чёрный, зелёный и красный в обеих темах, компактную верхнюю панель и сворачиваемую боковую навигацию. Состояние панели сохраняется локально и переносится с настройками JSON. На телефоне остаётся нижняя навигация. PNG-логотип создан встроенным image_gen; исходник и финальный промпт находятся в assets/, размеры для сайта и расширения готовит scripts/build-brand.mjs.
