# Курс за курсом: расширение Chrome 1.3

Расширение переносит отображаемые результаты Coursera в **[ваш трекер](https://rumm1.github.io/aitu-course-tracker/)** внутри браузера. Это локальное чтение страницы, а не официальное API-подключение.

## Установка и обновление

1. Скачайте `course-progress-extension.zip` **со своего сайта**, в разделе «Расширение и свой сайт», и распакуйте в постоянную папку.
2. В `chrome://extensions` включите «Режим разработчика» → «Загрузить распакованное расширение». Выберите папку с `manifest.json`.
3. В окне расширения подтвердите чтение своего списка и включите передачу прогресса.
4. Обновите Coursera и трекер. В [«Моём обучении»](https://www.coursera.org/my-learning) откройте «Завершённые» или «В процессе», дождитесь карточек и загрузите нужные строки.

Для обновления замените файлы в **той же папке**, нажмите ↻ у расширения в `chrome://extensions` и обновите Coursera и трекер. Метки сохраняются отдельно и остаются на месте.

Версия 1.3 читает все подходящие **отображаемые карточки**, включая новые курсы вне начального или Excel-каталога. Если на карточке есть название и допустимая официальная ссылка, новый курс автоматически появится в локальном трекере со своим доступным статусом и прогрессом. Сначала он находится **без предмета** и не увеличивает обязательный план; затем его можно распределить в «Моих предметах». Повторы не создают копий и не сбрасывают завершение.

В окне проверки видны раздел, время чтения и причина нулевого результата. Если по карточке нельзя однозначно определить курс, он не добавляется наугад. Откройте «Моё обучение», выберите раздел и дождитесь карточек.

Расширение не прокручивает страницу, не входит в аккаунт и не открывает скрытые разделы само. Оно видит только загруженные карточки: для старых завершений нужно открыть «Завершённые» и загрузить нужные строки. Автоматическое чтение видимого списка не означает автоматическую загрузку всей истории аккаунта. Процент без данных не придумывается; неоднозначное название остаётся на уточнение в трекере.

## Личная копия для каждого владельца

Создайте свой сайт через [шаблон репозитория](https://github.com/Rumm1/aitu-course-tracker/generate), включите **Settings → Pages → GitHub Actions** и запустите **Publish GitHub Pages**. Новая личная копия начинает с пустого каталога, плана и предметов: добавьте свои курсы, создайте предметы или загрузите Excel. Затем скачайте ZIP уже со своего опубликованного адреса.

Сборка использует `GITHUB_REPOSITORY` и привязывает расширение к адресу и пути конкретной копии. Данные передаются только этому сайту. ZIP основного сайта и личной копии не взаимозаменяемы по адресу трекера. Для основного репозитория ZIP также доступен в [релизе v1.3.0](https://github.com/Rumm1/aitu-course-tracker/releases/tag/v1.3.0).

## Данные и ограничения

- До явного включения ничего не читается. Единственное API-разрешение — `storage`.
- Скрипт подключается на `https://www.coursera.org/` для переходов внутри приложения, но читает курсы только на `/my-learning` и персональных страницах сертификатов Coursera. Другой скрипт обменивается данными только с адресом вашего трекера, указанным в этой сборке.
- Пароли, cookies, токены, история браузера, сетевые запросы и внутренние API Coursera не используются. Полный текст страницы не сохраняется и не отправляется на сервер.
- Локально сохраняются ID и метаданные найденных карточек — название и ссылка курса, доступный провайдер, статус, процент, найденная ссылка сертификата и время проверки. Трекер хранит каталог и отметки в IndexedDB, отдельно по origin и пути сайта. В GitHub личные данные не отправляются.
- Названия и распределение ваших предметов принадлежат трекеру. Курс можно включить в несколько предметов без изменения его статуса; скрытие или переименование предмета не стирает прогресс.
- Перед сменой аккаунта Coursera нажмите **«Отключить и очистить данные»**. Расширение не определяет владельца через cookies. Очистится кэш расширения; прежние отметки трекера останутся у владельца.
- Для переноса используйте JSON трекера. Он может содержать локальные курсы в массиве `courses`, но не переносит PDF и разрешение на папку. Очистка браузера без копии приводит к потере локальных отметок.
- Изменение разметки Coursera может потребовать обновления. На телефоне и без расширения используйте массовую вставку.

Исходники находятся в `extension/`, сборка — `node scripts/build-extension.mjs`. Проверки используют DOM-образцы и локальный мост; реальный авторизованный аккаунт Coursera при тестировании не использовался.

Персональная ссылка сертификата подставляется автоматически из карточки курса (включая ссылку, указанную в кнопке). Если Coursera открывает сертификат отдельной страницей, откройте её один раз: расширение прочитает адрес и точное название или ссылку курса. Неоднозначные страницы не привязываются; адрес сертификата не придумывается.
