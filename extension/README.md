# Курс за курсом: локальное расширение Chrome

Это необязательный способ переноса ваших отображаемых результатов Coursera в [трекер](https://rumm1.github.io/aitu-course-tracker/). Он не является официальным API-подключением к Coursera.

## Установка

1. Скачайте `course-progress-extension.zip` с сайта трекера и распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите распакованную папку, внутри которой лежит `manifest.json`.
4. Откройте значок расширения, подтвердите разрешение на чтение вашего списка и нажмите «Включить чтение моего прогресса».
5. Перезагрузите уже открытые страницы трекера и Coursera. В [«Моём обучении»](https://www.coursera.org/my-learning) откройте «Завершённые» и «В процессе». Загруженные на странице курсы попадут в трекер. Новые видимые результаты обновляются при изменении списка, возвращении во вкладку и периодически, пока страница видима.

Расширение не открывает разделы и не прокручивает страницы автоматически. Для всей истории загрузите нужные элементы списка сами. Если Coursera не показывает процент, расширение не придумывает его. Если название неоднозначно, выбор остаётся в трекере.

## Приватность и ограничения

- До включения через popup ничего не собирается.
- Единственное API-разрешение — `storage`; content scripts работают только на `https://www.coursera.org/my-learning` и странице трекера `https://rumm1.github.io/aitu-course-tracker/`.
- Нет доступа к паролям, cookies, сетевым запросам, токенам, другим сайтам, истории браузера или внутренним API Coursera.
- Локально сохраняются только распознанные ID курсов, статусы, проценты, найденные ссылки сертификатов и время проверки. Полный текст страницы не сохраняется и не отправляется на сервер. Обмен с трекером проходит внутри браузера.
- Перед сменой аккаунта Coursera нажмите «Отключить и очистить данные». Расширение не может надёжно определять владельца аккаунта без официального доступа к профилю.
- Если Coursera изменит структуру страницы, перенос может потребовать обновления. Массовая вставка в трекере остаётся доступной.
- Отключение очищает кэш расширения; уже сохранённые отметки в трекере остаются у вас. Ошибочную привязку можно отменить через документы трекера.

Исходники расширения находятся в `extension/`, сборка выполняется `node scripts/build-extension.mjs`. Авторизация и данные из реального личного аккаунта при тестировании не использовались; автоматические тесты проверяют правила объединения и DOM-образцы.
